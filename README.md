# 🛒 E-Commerce Sales Analysis using SQL

Analyzing sales, customers, and products for a retail business using SQL and Python.

## What This Project Covers
- Total revenue and business overview
- Revenue breakdown by product category
- Top 5 best selling products
- Top 10 customers by spending
- Monthly revenue trend analysis
- Order status breakdown (Delivered/Cancelled/Returned)
- Revenue by city
- Gender based buying behaviour
- Customer ranking using Window Functions (RANK OVER)
- High value customer segmentation using CTEs

## SQL Concepts Demonstrated
- INNER JOINs across 3 tables
- GROUP BY, ORDER BY, aggregate functions
- Window Functions — RANK() OVER
- CTEs — Common Table Expressions
- CASE WHEN statements
- Subqueries
- Date functions

## Key Business Insights
- Electronics drives highest revenue
- December generates 2x average monthly revenue
- 85% order delivery rate
- High value customers spend 2x more than average

## Tools Used
- Python, SQLite, Pandas, Matplotlib, Seaborn
